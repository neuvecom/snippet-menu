# SnippetMenu

クリップボードを使わずに定型文を入力できる、macOSのメニューバーアプリです。コピーした内容はそのまま残るので、定型文を入れたあとも`⌘V`で貼り付けられます。

配布ページ: https://neuvecom.github.io/snippet-menu/

## 更新情報

- 2026-11-24 v1.2.1: UUID入力、コピー履歴、Appleの公証に対応しました（[お知らせ記事](https://note.com/hebodan/n/ndf509160b8cd)）

## 機能

- メニューバーのアイコンから定型文を入力
- `⌥`+右クリック、または`⌃⌥V`でカーソル位置にメニューを表示
- タイトルを`分類/名前`にするとサブメニューに整理
- 日本語入力がオンのままでも入力可能
- 最近コピーしたテキスト5件をメニューから入力（メニューを開いて`1`〜`5`キーでも選択可）
- メニューを開かずに入力するショートカット: `⌃⌥1`〜`⌃⌥5`で最近のコピー、`⌃⌥U`でUUID
- 「UUIDを入力」で新しいUUIDを入力。定型文の中の`{uuid}`も、入力のたびに新しいUUIDに置き換え

## 動作環境

- macOS 13以降
- Apple Siliconで動作確認済み

## インストール

1. [最新版のSnippetMenu.zip](https://github.com/neuvecom/snippet-menu/releases/latest/download/SnippetMenu.zip)をダウンロードして展開します。
2. `SnippetMenu.app`を「アプリケーション」フォルダへ移動して開きます。
3. 「アクセシビリティ」でSnippetMenuを許可します。

配布版はDeveloper IDで署名され、Appleの公証を受けています。

## ソースからビルド

Xcodeのコマンドラインツールが必要です。

```bash
./build.sh
```

`~/Applications`にインストールされ、そのまま起動します。

署名なしでビルドすると、ビルドのたびにアクセシビリティの再許可が必要です。最初に一度だけ次のコマンドで自分用の署名証明書を作っておくと、再ビルドしても許可が保たれます。

```bash
./scripts/setup-signing.sh
```

## 仕組み

入力欄へアクセシビリティ機能で直接挿入します。対応していないアプリでは、キー入力として送ります。どちらの方法でもクリップボードは使いません。

キー入力で送るときの改行は、チャットアプリでの誤送信を防ぐため`Shift+Return`です。シェルでは改行で行が実行される場合があるため、複数行の定型文には注意してください。

定型文は`~/Library/Application Support/SnippetMenu/snippets.json`に保存され、外部には送信されません。コピー履歴はメモリ上にだけ保持し、アプリを終了すると消えます。パスワード管理アプリが「機密」として扱うコピーは記録しません。
