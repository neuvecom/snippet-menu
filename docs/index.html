3つの開き方

メニューバー
アイコンをクリックして定型文を選びます。
⌥ + 右クリック
マウスの位置にメニューを開きます。通常の右クリックはそのままです。
⌃⌥V
キーボードからメニューを呼び出せます。

タイトルを「分類/名前」にすると、サブメニューに整理できます。日本語入力がオンのままでも使えます。

「UUIDを入力」を選ぶと、新しいUUIDを入力できます。定型文に{uuid}と書いておくと、入力のたびに新しいUUIDに置き換わります。

メニューには最近コピーしたテキストが5件並びます。クリックするか、メニューを開いて1〜5キーで入力できます。メニューを開かずに⌃⌥1〜⌃⌥5で入力することもでき、⌃⌥UならUUIDを直接入力できます。履歴はアプリを終了すると消え、パスワード管理アプリが機密扱いにしたコピーは記録しません。

インストール

  1. SnippetMenu.zipをダウンロードして展開します。
  2. SnippetMenu.appを「アプリケーション」フォルダへ移動して開きます。
  3. Appleの公証を受けていないため、ブロックされた場合は「システム設定」→「プライバシーとセキュリティ」→「このまま開く」を選びます。
  4. 「アクセシビリティ」でSnippetMenuを許可します。文字の入力に必要です。

知っておきたいこと

  1. 定型文はMacの中にだけ保存され、外部には送信されません。
  2. 入力できるのはプレーンテキストのみです。書式や画像には対応していません。
  3. 直接挿入できないアプリでは、改行をShift+Returnとして送ります。シェルでは行が実行される場合があるため、複数行の定型文に注意してください。
  4. 動作確認はApple Siliconで行っています。

ソースからビルド
